## Task Description

The **Task Description** window is where you read what each task asks you to do. It contains the theory, the step-by-step instructions, code examples, images, and hints you need to complete your work.

When you are ready to submit a programming assignment, press the **Check** button. For theory tasks and quizzes, press the **Next** button <img src="images/edu_next_button.png" class="center" width=80> to continue.

To move between tasks manually, use the navigation arrows: ![](images/back.svg) goes to the previous task and ![](images/forward.svg) goes to the next one.

<style>
img {
  display: inline !important;
}
</style>

If you want to start a task again from scratch, use **Reset task** ![](images/reset.svg). If you get stuck, you can look at a reference answer with **Peek solution** <img src="images/edu_peek_solution.png" class="center" width=100>. Both actions are available from the ![](images/moreVertical.svg) menu.

The toolbar also lets you interact with the course: leave a question or report a problem on a task with **Comment** ![](images/commentTask.svg), switch the language of the task text with **Translation** ![](images/translation.svg), and share your opinion about the course with **Rate the course** ![](images/rateCourse.svg).

To free up space for the Editor, hide this window with ![](images/hideToolWindow.svg). You can always bring it back the same way.
